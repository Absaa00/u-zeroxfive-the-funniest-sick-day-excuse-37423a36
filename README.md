# The Funniest Sick-Day Excuse

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)

One line. One breath. One excuse.

This entry is for the make.fun bounty
[The Funniest Sick-Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36):
write a single line, under 200 characters, that someone could send to call
in sick — the funniest excuse that still lands in one breath.

## The excuse

> I woke up fluent in a language I don't speak, and my cat is the only one who understands me - staying home until one of us learns English again.

Why it works: the setup is half-plausible (waking up wrong is a feeling
everyone knows), the twist is fresh (fluency in an unknown language, with
the cat as the only translator), and the laugh lands mid-sentence — the
punchline is the negotiation with the cat, not a trailing tag. At 144
characters it fits the under-200 limit with room to spare, so it lands in
a single breath.

## Run it

```sh
python3 main.py
```

`main.py` is deterministic and uses no network: it prints exactly the one
excuse above and nothing else.
